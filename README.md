# Roadguard
It is used to Train AI for Educational and Research Purposes.

It uses AMD ROCm + Porch for AI Training

# AI Used and Involved:
## YOLOv8 (Ongoing)
- Mainly Used for Object Detection in a single Image Frame
## ByteTrack (Still Need Review)
- Similar to Yolo but its Multi-Object Tracking Detection across Multiple Video Frames, which is capable of finding and tracking objects longer.
## OCR (In Queue)
- Mainly Used for Reading Text from Images
